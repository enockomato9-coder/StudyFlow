# StudyFlow

> A student productivity and career-development platform for organizing learning, projects, skills, progress, and professional growth.

## Overview

**StudyFlow** is a student-focused productivity system that brings academic planning and career development into one organized workspace.

It helps students manage their semester, track progress, organize tasks and notes, document projects, build professional evidence, and prepare a CV from the work they complete.

This project is being developed as a practical software-engineering portfolio project.

## Core Features

- Student account creation and login
- Personal profile and professional information
- Semester and unit management
- Manual academic activity and schedule management
- Task and deadline tracking
- Calendar
- Notes
- Documents and project files
- Project workspace
- Skills and growth tracking
- Achievements
- Engineering/activity journal
- Progress tracking
- Focus timer
- CV Studio
- Professional portfolio
- Public read-only project presentation
- Contact section for portfolio visitors
- Backup and restore
- Responsive interface
- Dark/light interface options

## Project Portfolio

StudyFlow provides a project workspace for documenting projects with:

- Project title and description
- Technologies used
- Skills demonstrated
- Screenshots and images
- Project files
- Source code
- GitHub repository links
- Live project links
- Project status
- Development evidence

Public projects can be presented through a read-only portfolio so visitors can explore the work without accessing private account information.

## Privacy

StudyFlow separates private student information from information intended for public portfolio presentation.

Private areas such as personal settings, tasks, calendar information, account information, and other private records are not intended to be exposed through the public portfolio.

Only information deliberately marked for public presentation should appear in the public portfolio.

## Technology

The current version is built with:

- HTML5
- CSS3
- JavaScript
- IndexedDB
- Web APIs

The project is structured so it can evolve as requirements become clearer through testing and user feedback.
